# Breakout Game

一个使用Godot引擎开发的经典打砖块游戏，采用对象池模式优化性能。

## 项目概述

这是一个基于Godot 4.x的打砖块游戏，实现了完整的游戏循环、碰撞检测和对象池管理系统。本项目主要练习对象池的实现和应用。

## 核心组件

### 游戏实体类

#### Ball.cs
- **功能**: 控制球的运动和碰撞逻辑
- **特性**:
  - 实现了`IPoolable`接口，支持对象池管理
  - 支持球与挡板的粘附状态
  - 处理与墙壁、挡板、砖块的碰撞反弹
  - 动态生成圆形纹理
- **关键方法**:
  - `AttachTo()`: 将球粘附到挡板上
  - `OnSpawn()`/`OnDespawn()`: 对象池生命周期管理

#### Paddle.cs
- **功能**: 玩家控制的挡板
- **特性**:
  - 支持左右移动控制
  - 实现基于击球位置的反弹角度计算
  - 动态生成矩形纹理
- **关键方法**:
  - `HitByBall()`: 计算球击中挡板后的反弹方向

#### Brick.cs
- **功能**: 可被击碎的砖块
- **特性**:
  - 实现了`IPoolable`接口
  - 支持自定义颜色和尺寸
  - 被击中后自动返回对象池
- **关键方法**:
  - `Hit()`: 处理砖块被击中的逻辑
  - `SetColor()`: 设置砖块颜色

### 游戏管理类

#### Main.cs
- **功能**: 主游戏控制器
- **特性**:
  - 管理游戏生命周期（开始、胜利、失败）
  - 实现对象池的返回处理器
  - 处理生命值系统
  - 生成游戏场景（挡板、砖块、墙壁）
- **游戏机制**:
  - 3条生命值
  - 10x5的砖块阵列
  - 死亡区域检测

### 对象池系统

#### IPoolable.cs
- **功能**: 对象池接口定义
- **方法**:
  - `OnSpawn()`: 对象从池中取出时调用
  - `OnDespawn()`: 对象返回池中时调用

#### ObjectPoolReturnHandler.cs
- **功能**: 对象池返回处理器接口
- **作用**: 定义对象返回池中的标准接口

#### ObjectPool.cs
- **功能**: 通用对象池实现
- **特性**:
  - 支持预分配初始对象数量
  - 自动管理活跃和非活跃对象
  - 池耗尽时自动创建新对象
- **关键属性**:
  - `Active`: 当前活跃对象数量
  - `Inactive`: 当前非活跃对象数量

## 游戏控制

- **左右移动**: 使用方向键或A/D键
- **发射球**: 按下"发射"键（需要在Godot项目设置中配置）

## 技术特点

1. **对象池模式**: 优化内存分配，减少GC压力
2. **物理碰撞**: 使用Godot的2D物理引擎
3. **动态纹理**: 运行时生成游戏纹理
4. **组件化设计**: 清晰的职责分离
